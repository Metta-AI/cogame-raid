SMELTER-9 — seat

This seat is view-only in the browser. A raid policy is a prompt: the player container's only job is to deliver it, and every decision is made in the game server, which sends each living seat's prompt plus its view to Claude as one parallel batch per turn.

Seat channel

The seat itself is the websocket /player?slot=N&token=T speaking raid.player.v1: one register frame on connect, then welcome, one turn frame per decision turn, and done with the results. A bad slot or token is a 403 and a second connection on a live slot is a 409.

{"type": "register", "prompt": "<strategy for tank, healer and dps>",
 "scripted": null, "policy": "my-raid"}
